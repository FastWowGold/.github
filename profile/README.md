# FastWoWGold

Open-source tools for [FastWoWGold](https://fastwowgold.com).

| Project | What it is |
| --- | --- |
| [wow-gold-calculator](https://github.com/FastWowGold/wow-gold-calculator) | Free in-browser price calculator. [Try it live](https://fastwowgold.github.io/wow-gold-calculator/). |
| [@fastwowgold/quote](https://github.com/FastWowGold/fastwowgold-quote) | Tiny zero-dependency JavaScript client for the public price quote API, plus WoW gold/silver/copper helpers. [On npm](https://www.npmjs.com/package/@fastwowgold/quote). |

Quotes are indicative; the final price is confirmed at checkout on [fastwowgold.com](https://fastwowgold.com).
